# Décisions d'architecture (ADR)

Une ADR note une décision qui structure le projet : le contexte, le choix, les
conséquences. Courte (une page). On ne la réécrit pas quand on change d'avis : on en ajoute
une nouvelle qui la **remplace**, et on marque l'ancienne « Remplacée par NNNN ».
